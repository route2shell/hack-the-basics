# Enumeration with Nmap — Course Outline v1

## Course Positioning

This course is designed as a self-paced, self-learning course on **Enumeration with Nmap**. It teaches from the ground up : first the mindset, then the mechanics, then the packet-level understanding, then professional workflow.

The structure is intentionally designed to:

- teach **enumeration as a discipline**, not just Nmap syntax
- move from **simple concepts to packet-level reasoning**
- blend **theory, command usage, visual learning, and labs**
- reinforce a consistent learning loop:
  - concept
  - protocol/mechanic
  - Nmap usage
  - interpretation
  - lab
  - quiz

---

## Design Principles

### What this course emphasizes

- Understanding **why** Nmap behaves the way it does
- Reading scan results in context instead of memorizing flags
- Connecting protocol behavior to scan output
- Using Nmap as part of a broader enumeration methodology
- Saving, parsing, comparing, and documenting results like a professional
- Knowing when automation helps and when manual enumeration is required
