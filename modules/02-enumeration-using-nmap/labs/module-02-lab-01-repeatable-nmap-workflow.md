## Planned Lab Structure

This lab will be implemented as a guided workflow with:

1. scope and target definition
2. host discovery
3. TCP triage scan
4. focused enrichment
5. saved artifacts and notes
6. next-step routing

---

## Expected Learner Artifacts

- target list or scope note
- saved scan outputs
- identified live hosts
- open-port summary
- service-enrichment summary
- follow-up questions

## Design Notes

When fully implemented, this lab should feel like an operational checklist with checkpoints, not a loose practice note.
